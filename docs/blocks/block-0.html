Block 0 · Orientation

Start here — how to use this playbook

This is not a cheat sheet you skim. It is a build order. Each block adds exactly one new idea, hands you the code for both apps, and makes you run it before moving on. Miss a block and the next one feels like magic; follow the order and nothing is magic.

🧱 Blocks 1–6

Foundation: install, pipeline syntax, Git, build, test. You become usable.

⚙️ Blocks 7–15

Real engineering: secrets, Docker, webhooks, RBAC, agents, shared libraries, multibranch. You become hireable.

🛡️ Blocks 16–24

DevSecOps, deploy, scale, troubleshoot, interview kit. You become expensive.

0.3 How to study (this matters more than the reading)

  1. Read one block. Then do it. Every block ends with a checklist. If you can't tick it, you haven't finished the block.
  2. Type, don't blindly paste. The copy button saves your fingers, not your brain. Change something — a stage name, an image tag — and see what breaks.
  3. Break it on purpose. Remove the credentials ID, use a bad branch name, forget sh. The error tables are written from failures you should cause yourself at least once.
  4. Use Replay. Job page → Replay → edit → Run. Iterate in seconds without polluting Git history. Commit only when green.
  5. Do it twice. Once for Node, once for Python. That repetition is the difference between "I followed a tutorial" and "I can do this for your repo".
